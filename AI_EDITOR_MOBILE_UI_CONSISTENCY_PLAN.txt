        tactile tabs:

        (`generating` / `editing`), so if the user is on the Chat tab on mobile
        and triggers an edit, or switches to Live Preview while streaming, they
        have 1-tap access to both panes at 100% mobile screen width!

        When `isActive && !sidebarCollapsed`, hide the right pane on `< 768px`
        (`hidden md:flex flex-1 flex-col overflow-hidden bg-[#070709] min-w-0`),
        and when `sidebarCollapsed` is true (or `!isActive`), show it full-width
        on all viewports (`flex flex-1 flex-col overflow-hidden bg-[#070709] min-w-0`).
      * Result:
        - On Desktop (`md:` and up): 100% identical side-by-side split view
          (`md:w-[420px] lg:w-[460px] xl:w-[480px]`) with the existing collapse
          button.
        - On Mobile (`< 768px`): Both the AI Vibe Design Assistant and the Live
