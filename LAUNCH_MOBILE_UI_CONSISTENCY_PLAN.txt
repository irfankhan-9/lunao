1. ZERO-DESKTOP-REGRESSION ARCHITECTURAL MANDATE
================================================================================

1.1 Responsive Breakpoint Rule (How Mobile-Only Changes Work in Tailwind CSS)
- In Tailwind CSS, unprefixed utility classes apply from `0px` upward, and
  prefixed classes (`sm:`, `md:`, `lg:`) override them at `640px+`, `768px+`,
  and `1024px+`.
- RULE FOR EVERY EDIT IN THIS PLAN:
  Whenever a base class is adjusted for mobile (e.g. changing `p-6` to `p-4` or
  `px-6 py-3` to `px-3 py-2.5`), the original desktop value MUST be explicitly
  locked at `sm:` or `md:` (e.g. `p-4 sm:p-6`, `px-3 py-2.5 sm:px-6 sm:py-3`).
- Where a mobile-specific flex/grid behavior is needed (such as stacking a row
  on mobile while keeping a horizontal row on desktop), use:
  `flex-col sm:flex-row` or `grid-cols-1 sm:grid-cols-3` while preserving the
  exact desktop alignment (`sm:items-center sm:justify-between`).

1.2 Sacred Functional & Data Guardrails
- Zero changes to state hooks, API calls, credit calculations, OAuth flows,
  CSV parsing, Google Dork SSE streaming, Telnyx eligibility checks, or
  Cloudflare deployment pipelines.
- Raw HTML templates in `/public/templates-raw/` are never touched.
- Audio feedback triggers (`playSoftTap`, `playGentleChime`, etc.) remain
  untouched.

================================================================================
2. CANONICAL MOBILE UI DESIGN TOKENS (LAUNCH SECTION STANDARD)
================================================================================

Every card, step, header, button, and modal inside the Launch section will obey
these unified mobile tokens on `< 640px` screens while restoring desktop tokens
at `sm:` / `md:`:

- Outer Wizard / Section Card Padding:
  Mobile: `p-4` (`16px`) | Tablet/Desktop: `sm:p-6 md:p-8` (`24px` / `32px`)
- Inner Feature / Specification Card Padding:
  Mobile: `p-3.5` or `p-4` | Desktop: `sm:p-5` or `sm:p-6`
- Section Titles (`h2` / `h3` Serif Headings):
  Mobile: `text-xl` (`20px`) | Desktop: `sm:text-2xl` (`24px`)
- Page Main Title ("Launch"):
  Mobile: `text-2xl` (`24px`) | Desktop: `sm:text-4xl` (`36px`)
- Segmented Tab / Lead-Source Pill Switchers:
  Mobile: `w-full grid grid-cols-2` (or `flex w-full overflow-x-auto no-scrollbar`)
          with `px-3 py-2.5 text-xs justify-center`
  Desktop: `sm:w-fit sm:flex sm:px-6 sm:py-3 sm:text-sm`
- CSV Upload Dropzones:
  Mobile: `p-6` with `w-14 h-14` icon container
  Desktop: `sm:p-12` with `sm:w-20 sm:h-20` icon container
- Wizard Bottom Navigation Bar (`Back` / `Next Step` / `Launch`):
  Mobile: `px-4 py-3.5` with touch-friendly `min-h-[42px]` buttons
  Desktop: `sm:px-6 sm:py-4`
- Modal Overlays (`CampaignDetailModal`, `DorkConfirmModal`, `CreateNicheModal`):
  Mobile: `p-2.5 sm:p-4`, inner card `max-h-[92vh] sm:max-h-[90vh] rounded-2xl`
  with `onMouseDown={(e) => e.stopPropagation()}` so scrolling/dragging never
  accidentally closes the modal.
